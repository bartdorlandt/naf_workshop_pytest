## Agenda

!!! note "Agenda to be discussed"

    This agenda is a draft proposal and subject to optimization based on proctor discussion. Timing and content may be adjusted.

### 14:00-14:15

Theory - Introduction: Welcome & setup check, intro of proctors, workshop goals, Python environment verification, pytest installation.


### 14:15-14:45

Theory - Designing Testable Code: Why testability matters, separating business logic from device interaction, dependency injection basics.


### 14:45-15:15

Lab - Refactoring for Testability: Take a tightly coupled automation script and refactor it into clean, testable modules.


### 15:15-15:45

Theory - PyTest Fixtures: Understanding fixtures, scope, and reusability. How fixtures help isolate test dependencies.


### 15:45-16:15

Break - Coffee, a lot of coffee. ☕☕☕


### 16:15-16:45

Lab - Working with Fixtures: Create fixtures for common test scenarios, use fixture scope effectively.


### 16:45-17:15

Theory & Lab - Mocking: Introduction to unittest.mock and pytest-mock. Mocking device drivers, APIs, and simulating failures (timeouts, auth errors, partial config pushes).


### 17:15-17:35

Theory & Lab - Parametrization: Using pytest.mark.parametrize for data-driven testing, testing multiple scenarios efficiently.


### 17:35-17:50

Theory & Demo - CI/CD Integration: Integrating pytest into GitHub Actions, generating test reports, best practices for automation pipelines.


### 17:50-18:00

End - Questions, Demo, next steps, feedback!
